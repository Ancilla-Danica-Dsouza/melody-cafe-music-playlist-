# Changelog

## 1.2.0
- Download / save copy as Full song (default) or 10 second clip, online and offline
- Jamendo provider for free full-length songs (free key)
- iTunes backup provider, SSL / network diagnostics

- Online music search window (Deezer public API, 30 second previews)
- `--online-test` command

## 1.0.0
- Doubly circular linked list playlist
- tkinter GUI with 14 themes (6 UAE themes)
- Multi-backend audio (Windows MCI, system players, pygame)
- Save / load playlists, search, shuffle, repeat, volume
